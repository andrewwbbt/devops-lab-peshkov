# Contributing

## Правила участия в проекте

1. Все изменения выполняются в отдельной ветке.
2. Перед началом работы необходимо обновить локальный репозиторий.
3. Коммиты должны иметь понятные сообщения.
4. Изменения добавляются в основную ветку через Pull Request.
5. Перед слиянием необходимо проверить внесенные изменения.
6. Нельзя добавлять пароли, приватные ключи и другие конфиденциальные данные.
